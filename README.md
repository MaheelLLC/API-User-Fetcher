## API User Fetcher

### What the Application Does
This application retrieves data for 10 users from JSONPlaceholder. Then, it reformats the user data into only containing the user's name, username, email, and city.

### Requirements
- Python 3.13 and pip installed
- Created Python venv called venv
- Requests library installed in venv

### Installation and Execution Instructions
1. Make a copy of this repository in your local computer.
2. Move into the repository's directory
3. Enter in your terminal `python3 -m venv venv`
4. Enter in your terminal `pip install -r requirements.txt`
5. Enter in your terminal `python3 main.py`
